# Observability Engineering — Starter Kit

Hands-on starter kit for **DPE-450 · Observability Engineering** in the Data Platform Engineering (DPE) Professional Certificate.

## Release status

**Released** — v1.6.1 on 2026-08-24. This kit is feature-complete and
maintained for the 2026 Fall cohort. Issues and pull requests are welcome.

## What is included

- `src/telemetry.py` — the reference implementation used in the live sessions and
  the lab exercises.

## Getting started

Open `src/telemetry.py` and follow the module docstrings; the runner class there
is the same one demonstrated in the live sessions. The datasets referenced by
the exercises are distributed through the Data Platform Engineering (DPE) Professional Certificate learning platform.

Published under `kits/dpe-450-observability-kit/` in the capstone catalog repository.
